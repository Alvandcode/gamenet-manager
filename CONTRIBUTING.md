# Contributing / مشارکت

## Issues

Before opening a new issue, please check existing issues. When reporting a bug, include:

* Android device model and version
* App version
* Description of the problem and steps to reproduce
* Screenshot or log if possible

برای گزارش مشکل ابتدا Issueهای موجود را بررسی کنید و در گزارش باگ، مدل دستگاه، نسخه اندروید، نسخه برنامه و مراحل بازتولید مشکل را ذکر کنید.

## Pull Requests

1. Fork the repository and create your branch from `main`.
2. Keep changes focused — one PR per feature/fix.
3. Test your changes locally (`npx cordova run android` or open `www/index.html` in a browser).
4. Do not commit `node_modules/`, `platforms/` or `plugins/`.
5. Security vulnerabilities must be reported privately (see README "امنیت" section) — not via public issues.

برای تغییرات بزرگ ابتدا در یک Issue درباره آن بحث کنید. آسیب‌پذیری‌های امنیتی را خصوصی گزارش کنید.
